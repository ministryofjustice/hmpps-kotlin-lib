# 3.0.0

Upgrade to spring-boot [4.1.0](https://github.com/spring-projects/spring-boot/releases/tag/v4.1.0).

The spring boot release pulls in a spring security
bug (https://github.com/spring-projects/spring-security/issues/19324). This release includes an additional
`ServletRequestResponseNonNullFilterFunction` filter function to workaround the issue.

If you are using the `authorisedWebClient` method in `HmppsWebClientConfiguration.kt` then the filter function will be
automatically applied and no further action is necessary. If not you will need to apply the filter function manually by
adding in:

```kotlin
  .filter(ServletRequestResponseNonNullFilterFunction())
```

before the call to the oauth2 filter function.

Note that this bug only affects servlet environments, reactive applications will be unaffected and workaround is
required.
